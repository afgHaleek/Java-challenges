# Challenge 02 - Simple Calculator
**Difficulty:** 2/100

### 🎯 Goal
Write a program that acts as a simple calculator:
1. Reads two numbers from the user.
2. Asks for an operation (`+`, `-`, `*`, `/`).
3. Performs the calculation.
4. Prints the result.

### 📚 Concepts Covered
- Using `Scanner` for user input.
- Decision-making with `switch` or `if-else`.
- Arithmetic operations (`+`, `-`, `*`, `/`).
- Handling invalid input (e.g., division by zero).
- Understanding `Scanner.nextLine()` vs. `Scanner.next()`.
