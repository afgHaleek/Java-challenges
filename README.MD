# Java Challenges Repository

🎯 **Purpose**  
This repository is a collection of Java programming challenges designed to practice **core Java**, **object-oriented programming**, and **unit testing**. Each challenge is written in a **clean, testable manner**, with corresponding **JUnit 5 tests** to ensure correctness and demonstrate professional coding practices.

---

## 🛠 Technologies & Tools
- Java 21
- JUnit 5 for testing
- Maven for project management

---

## 📂 Project Structure

java-challenges/
│
├─ src/main/java/
│ ├─ challenge00/HelloWorld.java
│ ├─ challenge01/SumTwoNumbers.java
│ ├─ challenge02/SimpleCalculator.java
│ ├─ challenge03/NumberClassification.java
│ ├─ challenge04/ArrayOperations.java
│ └─ challenge05/StringManipulation.java
│
└─ src/test/java/
└─ ... (JUnit test classes corresponding to challenges)

## 🏃 How to Run

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/java-challenges.git
cd java-challenges

2. Compile the project
mvn compile

3. Run Challenge
mvn exec:java -Dexec.mainClass="challenge01.SumTwoNumbers"
Replace challenge01.SumTwoNumbers with the fully qualified class name of the challenge you want to run.

4. Run all unit test
mvn test
